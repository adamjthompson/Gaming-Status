# Manage Players
Add, edit, or delete the gamers in your household.

* **Platform Sensors:** When adding a player, you simply select their respective integration sensors from the dropdowns. Every slot is a searchable dropdown: the integration filters your entities to show the correct Steam (`sensor.steam_*`), Xbox (`sensor.*_status`), PlayStation (`sensor.*_now_playing`), Playnite (MQTT `binary_sensor.*_playnite_playing_game`), and Gaming Status Agent (MQTT `sensor.gsa_*`) entities. The Custom platform accepts any sensor whose state is the game title (or on/off), e.g. `sensor.player_one_active_pc_game` (see [Tracking PC Games with a Custom Sensor](../setup/pc-tracking.md#tracking-pc-games-with-a-custom-sensor)). You can include as few or as many platforms as a player owns. Default sensor names from the platform integrations: Steam `sensor.steam_playername`, Xbox `sensor.playername_status`, PlayStation `sensor.playername_now_playing`, Gaming Status Agent `sensor.gsa_profilename`. *(Note: To remove a previously assigned sensor, choose **none** at the top of its dropdown and click Submit. The integration will save the empty state and stop tracking that platform. If an entity you need isn't listed, you can type its entity ID into the dropdown.)*
* **PS3 Media Player:** *(Only shown when a player has a PlayStation sensor configured, and PS3 Tracking is enabled under Global Settings)* The PS3 predates the modern PlayStation Network status API, so it can't be tracked the same way as PS4/PS5 — instead, select its `media_player.*` entity (also provided by the official PlayStation Network integration). PS3 activity feeds directly into that player's existing PlayStation sensor and history, rather than creating a separate sensor.
* **Epic account:** *(Optional; only shown when Epic Games is checked under [Global Settings](global-settings.md))* The player's public Epic profile link (or 32-character account ID), used for the Epic library scan (which needs nothing else) and for Epic achievements on games Gaming Status Agent reports from the Epic launcher. Epic online status itself only comes from Gaming Status Agent, since Epic has no status sensor. The profile and its achievements must be public. See [Epic Games Achievements](../getting-started/prerequisites.md#epic-games-achievements). It sits with the platform sensors, above Discord. Clear the field to stop using it.
* **Player Details:** After adding a player, you can configure:
    * **Session Notifications:** Select notification methods separately for when this specific player starts gaming and when they stop. *Note: These must be configured under Notifications.*
    * **Suppress other players' Xbox sensors:** Configured on the player whose *own* sensor(s) are accurate. Pick which other players' Xbox sensors should be suppressed whenever this player is confirmed playing on any of their own enabled platforms — including their own Xbox sensor. Fixes a shared-PC Xbox app misattributing this player's session to someone else's Xbox account. Suppressed sensors ignore that same game and show `xbox_suppressed: true`. *Only for cross-player mixups; the same player's own overlapping sensors are already handled automatically.*
    * **Exclude Games:** One game per line (case-insensitive) to ignore for this specific player. This  applies to both current-game tracking and their full game library scan (see [Overrides & Exclusions](overrides-exclusions.md) for exactly how matching works).
    * **Show on public page:** Include this player on the [Public Page](public-page.md). Off by default.
    * **Achievement/Trophy Tracking & Library Scan (per platform):** *(Only shown when the matching global toggle under [Achievements & Ratings](achievements-ratings.md) is on)* Per-player Steam/Xbox/PlayStation/Epic/Ubisoft checkboxes to turn achievement tracking and the full library scan on or off for each of this player's configured platforms individually. Epic appears once the player has an Epic account set (and Epic Games is checked under Global Settings); Ubisoft appears once the player has a Gaming Status Agent sensor (and Ubisoft is checked under Global Settings).
    * **Clear achievement/trophy history:** *Use with caution.* The last item on the screen. Permanently deletes this player's entire recorded achievement/trophy unlock history, across every platform they're tracked on. Applies once on the next reload, then automatically switches itself back off — unlike other settings, you don't need to remember to undo it.

## Custom User Avatars

If you want to replace the gamer avatar with one of your own or if you want to provide an avatar for a Gaming Status Agent sensor you only need to add an image to the `www/gaming_status` folder. The folder will need to be added manually. For your images, use JPEG or PNG images named as `platform_username_avatar.ext`. So, for a user named John on Xbox, it should be 'xbox_john_avatar.png', for John's Gaming Status Agent sensor, 'gsa_john_avatar.png', and for his Custom sensor, 'custom_john_avatar.png'.

Any images added manually in this way will take priority over whatever is provided by the platform integration.

You can also add a default avatar named `default_username_avatar.ext` (for example, 'default_john_avatar.png'). It's used on any platform where John has no platform-specific image and the platform provides no avatar, such as games tracked through Epic or Ubisoft. If no default avatar exists, the generic controller icon is shown.

# Achievements & Ratings
Native achievement/trophy/rating enrichment and full game library scanning, all in one place -- every field here is always visible together, regardless of which toggles are on, so you never have to save and reopen the menu just to find a setting.

* **Enable Native Content Ratings:** See [Content Ratings](../getting-started/prerequisites.md#content-ratings). Off by default. Independent from achievement tracking below — Steam ratings need no credential at all, while Xbox and PlayStation each reuse the same session achievement tracking uses (Xbox's numeric age limit is still free either way, from the same official Xbox integration sensor it always was; the credential is only needed for the ESRB/PEGI text label alongside it). This same setting is also shown on the main Parental Controls screen.
* **Enable Achievement/Trophy Tracking:** Adds achievement/trophy counts and recent-unlock details to the current game's Steam/Xbox/PlayStation sensor, and to the Gaming Status Agent sensor for Epic games when the player has an [Epic account](../getting-started/prerequisites.md#epic-games-achievements) set. Epic games reported only through Discord aren't covered, since Discord doesn't say which store a game came from. Off by default; the recheck interval and library scan fields below only take effect once this is on. To use a different Steam key or PSN NPSSO than the official integrations', see the credential overrides under [Advanced Settings](advanced-settings.md). Once this is on, each player's **Player Details** screen also offers **Achievement/Trophy Notification(s)** (see [Notifications & Reporting](notifications-reporting.md#how-to-configure-notifications)).
* **Achievement/Trophy Recheck Interval:** How often to re-check for newly-earned achievements/trophies while a game keeps running (Steam, PlayStation and Epic). Default 900 seconds (15 min), minimum 300 (5 min). A new Epic unlock therefore shows up within this interval.
* **Enable Full Game Library Scan:** Adds a Game Library sensor (plus one per tracked platform) with your full game collection — total achievements/trophies, completion percentage, and per-game details — scanned periodically in the background. Only created for platforms you already track, plus Epic for players with an Epic account set. The Epic library lists the games on the player's public profile, which are the games with at least one Epic achievement unlocked. Games matching Global Exclusions or that player's own Exclude Games list (see [Overrides & Exclusions](overrides-exclusions.md)) are skipped entirely. Off by default.
* **Library Scan Interval:** How often to rescan your full game library. Default 12 hours, range 1–24.
